--- 6. notes / gotchas (for the module doc) ---
* dvc 3.67.1 rejects the dagshub:// URL scheme:
    Unsupported URL type 'dagshub://...'
* there is no `dvc dagshub-setup` subcommand, and dvc[dagshub] is not a real extra.
* working recipe: `dvc remote add -d storage https://dagshub.com/<owner>/<repo>.dvc`
  + HTTP basic auth stored only in .dvc/config.local via `dvc remote modify --local storage user <name>`
  and `dvc remote modify --local storage password <token>`.
* order matters: dvc push BEFORE git push (DagsHub host key must be trusted once on first push).
